# Novatech

A responsive e-commerce website for mobile accessories, built with React.

## Features

- Responsive design for laptops and mobile devices with a minimum width of 410px
- Product listing
- Shopping cart
- Quantity management
- Order summary
- Login / Register
- Persian / English language support
- Light / Dark theme
- React Router
- LocalStorage for user and cart data

## Technologies

- React
- JavaScript
- CSS
- React Router
- React Icons
- LocalStorage
